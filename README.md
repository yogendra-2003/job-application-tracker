# Job Application Tracker

A responsive job application tracking dashboard built with React.js to help organize and monitor job applications.

## Features

- Add new job applications
- Edit and delete existing applications
- Track company names, job roles, dates, and application statuses
- Search applications by company name or job role
- Filter applications by status
- View application statistics on the dashboard
- Save application data using browser localStorage
- Responsive layout for desktop and mobile screens

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser localStorage
- Git and GitHub
- Vercel

## Run Locally

1. Clone this repository.

2. Open the project folder in a terminal.

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
